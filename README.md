# 天命降临（Destiny Descends）

钢铁雄心 4（HOI4）天命主题 mod —— 通过**决议**为玩家提供**分档、可随时切换、全方位**的天命祝福。

> HOI4 Destiny Descends mod: player-only decisions that grant switchable, all-around national blessings. AI can never use them.

## ✨ 特性

- 🎮 **仅玩家可用**：决议与分类均通过 `is_ai = no` 限制，AI 无法使用
- 🎚️ **三档可随时切换**：天命初醒 / 天命加身 / 天命之主，档位决议常驻显示，点哪个直接切换（自动移除旧档位，**绝不叠加**）
- 🚫 **一键收回**：点「收回天命」移除当前档位，恢复正常状态
- 🌐 **全方位增益**：覆盖政治、工业、陆海空三军、人力、外交、后勤、情报等 92 / 94 / 95 项（轻 / 中 / 重档）
- ⛏️ **资源采购**：花费 20 政治点，让随机一个本国核心州永久获得 +100 对应资源；支持钢、铝、钨、铬、石油、橡胶与煤炭
- 🎖️ **将领系统扩展**：加入 15 个已本地化的陆海军特质，相关技能表扩展至 20 级，并调整基础指挥点与特质槽位
- 🗣️ **双语本地化**：简体中文 + English
- 🎯 兼容游戏版本 **1.19.\***

## 📦 安装

1. 下载本仓库 `mod_2008/` 文件夹与 `mod_2008.mod` 文件（或 Releases 中的 zip）
2. 放入 `Documents\Paradox Interactive\Hearts of Iron IV\mod\`
3. Paradox 启动器中启用「天命降临」（Tags: Gameplay）
4. 进入游戏 → 决议面板 → 「天命帷幄」分类 → 选择档位

## ⛏️ 资源采购

「资源采购」分类包含 7 个可重复决议。每次花费 20 政治点，在随机一个**本国拥有的核心州**永久增加 +100 对应资源。该逻辑已使用 HOI4 1.19 的有效州级触发器 `is_core_of = ROOT`。

## 🎖️ 将领扩展

- 15 个带中英文名称与说明的陆军、元帅和海军特质
- 陆军将领、元帅和海军的相关技能表扩展至 20 级
- 基础指挥点上限调整为 250，基础获取调整为 0.5
- 调整将领可分配特质槽位的成长规则

## 🛠️ 构建流程

本 mod 通过 [hagane.works](https://scharnhorst.hagane.works)（钢之工坊）平台构建：

- 平台项目 ID：`2008`；当前包含 11 个决议、2 个决议分类、3 个民族精神和 5 个原始覆盖文件
- `scripts/update_v*.py` 是按版本保留的迁移脚本，不存在单一的“当前更新脚本”
- API 操作需要 `HOI4_PLATFORM_URL` / `HOI4_PLATFORM_TOKEN`，令牌**绝不入库**
- 导出前运行 `export/validate` 与 `lint/tree-validation`，导出后仍须实际启动游戏并检查 `logs/error.log`
